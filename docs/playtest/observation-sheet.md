# Playtest observation sheet (GDD E.5)

Source: [`docs/gdd/appendix-e-playtest.md` §E.5](../gdd/appendix-e-playtest.md#e5-observation-sheet). Issue: SB-53 (#44).

One section per tester. Record concrete behaviour, such as "walked off a band during the ring-drop warning",
instead of general remarks such as "the player did not understand". Write interpretations separately so that
inference is not mixed with observation. Record every help given. Video or audio only with consent.

## PT codes (GDD E.4)

| Code | Situation |
|---|---|
| PT01 | Newcomer completes the Training Ring tutorial |
| PT01b | Pick a fruit in the 3D lobby and get ready |
| PT02 | Approach, collide and hold position |
| PT03 | Same level with a Heavy and a Light fruit |
| PT04 | Moving Ground |
| PT05 | Air and fire cannons |
| PT06 | Cracking tiles |
| PT07 | Chaos Core |
| PT08 | Rings drop on L1, or last 10 s on L2–L5 |
| PT09 | A player falls under each rule |
| PT10 | A Multiplayer session ends |
| PT11 | One round with sound off |
| PT12 | Replay after a match |
